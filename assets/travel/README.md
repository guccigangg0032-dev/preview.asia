# Фотографии путешествий

Оптимизированные WebP-файлы находятся в архиве для загрузки. `travel-gallery.js` автоматически показывает фотографии на главной странице при их наличии в этой папке; отсутствующие изображения не создают пустых или сломанных блоков.

Не представлять эти фотографии доказательством трудоустройства или выдачи виз.
