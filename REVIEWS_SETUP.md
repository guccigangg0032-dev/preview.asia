# Видеоотзывы — инструкция по наполнению

Раздел `reviews.html` читает файл `reviews-data.json`. В демонстрационной версии массив `items` пуст: истории не выдуманы.

## Добавление YouTube

1. Загрузите согласованный отзыв на YouTube (публично или «доступ по ссылке»).
2. Убедитесь, что для ролика разрешено встраивание на другие сайты.
3. В файл `reviews-data.json` добавьте объект. Например:

```json
{
  "items": [
    {
      "platform": "youtube",
      "videoId": "ПОСТАВЬТЕ_ID",
      "url": "https://www.youtube.com/watch?v=ПОСТАВЬТЕ_ID",
      "country": "Польша",
      "title": "Название согласованной истории",
      "summary": "Кратко, о чем рассказывает кандидат.",
      "approved": true
    }
  ]
}
```

`videoId` — 11 символов из адреса YouTube; запись с неправильным ID автоматически пропускается.

YouTube видео загружается **только после нажатия** на карточку, чтобы не нагружать мобильную версию.

## Добавление Instagram Reel

Для публичных публикаций можно создать объект с `platform: "instagram"`, полем `url` вида `https://www.instagram.com/reel/...`, названием, страной и `approved: true`. Он откроет Instagram отдельно, без тяжелого встраивания.

## Перед публикацией

- Получите согласие снятых людей на размещение изображения, голоса и истории.
- Не размещайте сканы виз/паспортов, номера документов, даты рождения, адреса и иные персональные сведения.
- Проверяйте, что подписи не обещают трудоустройство, визу или доход без подтверждения.
- Не добавляйте вымышленные отзывы.
- DNS, GitHub Pages custom domain и сертификат TLS этим изменением не затрагиваются.
