# SEO и GEO: подготовка к запуску

Дата подготовки: 2026-10-30

## Реализовано
- Уникальные title и description для основных разделов; canonical URLs.
- Open Graph/Twitter-метатеги для ссылок.
- JSON-LD schema.org: Organization, WebSite и WebPage, BreadcrumbList для внутренних страниц.
- robots.txt и sitemap.xml для основных информационных страниц (без архивных карточек вакансий).
- guide.html: памятка кандидату с ответами на важные вопросы.
- Внутренние ссылки на памятку.
- Единая политика noindex,nofollow: демонстрационная версия закрыта от индексации, включая фотоархив.

## Не сделано сознательно
- Индексация НЕ открыта. Перед запуском потребуется согласовать права на изображения, вакансии, тексты и условия услуг.
- Не добавлена JobPosting-разметка для 53 архивных вакансий: актуальность и наличие свободных мест не подтверждены. Эта разметка может быть добавлена только для подтверждённых действующих вакансий, на отдельных страницах.
- Не добавлены hreflang для восьми языков: переводы сейчас работают внутри одного URL через JS, без отдельных индексируемых локализованных страниц. Для международного SEO нужны качественные переводы, URL под каждый язык и взаимные hreflang.
- Не использованы искусственные рейтинги, отзывы, обещания выдачи виз, сроки и зарплаты.
- llms.txt не нужен для появления в Google AI Overviews/AI Mode; важнее реальные тексты, структура и обычная SEO-индексация.

## Перед запуском
1. Проверить правдивость контактных данных, официальное название организации, адрес и юридические сведения.
2. Утвердить изображения и права; обновить фотоархив и отзывы при наличии согласий.
3. Проверить каждую вакансию, удалить/закрыть истёкшие, указать реальные даты и условия.
4. Удалить демо-уведомления и только затем заменить noindex,nofollow на index,follow для одобренных страниц. Не открывать 53 архивные вакансии автоматически.
5. Пройти Rich Results Test и URL Inspection Google, проверить Яндекс Вебмастер, отправить sitemap после открытия индексации.
6. Проверить отображение Google и Яндекс на телефоне и ПК; провести Core Web Vitals, SEO-аудит мета, оговорки и доступность.
7. Если нужны RU/KZ/EN/SR/KY/UZ/TG/AZ в органическом поиске, подготовить полноценные переводы и отдельные языковые URL.
